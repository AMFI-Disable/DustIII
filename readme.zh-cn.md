## ⚡ 概述与核心价值 <a id="overview"></a>

DustIII 是在浏览器中原生复刻经典 de_dust2 5v5 拆弹循环的项目。你手持步枪，四名机器人队友与你一同架点，五名敌方机器人会像一支协同作战的队伍那样购买、转点、执行战术与回防。每一回合都在单个页面中本地模拟——没有账号、没有匹配服务、无需下载、没有遥测。

项目面向桌面版 Chrome、Firefox 与 Safari，需要 WebGL 2。冷启动会从同源加载静态地图与美术资源包，随后在现代 GPU 上以 60+ FPS 运行整场比赛。

## 🎮 主要特性 <a id="features"></a>

### 竞技规则与经济 <a id="rules"></a>

- **MR12 赛制**：先赢 13 回合者获胜，第 12 回合后交换阵营，最多 24 回合结束比赛。
- **真实经济**：初始 $800，上限 $16,000，$1,400 至 $3,400 的连败补偿阶梯，击杀奖励，以及下包或拆包奖励。
- **冻结与购买时间**：每回合 15 秒冻结时间与 20 秒购买窗口。
- **完整炸弹流程**：3.2 秒下包、40 秒 C4 倒计时、10 秒拆包，携带拆弹器时为 5 秒。

### 武器沙盒

- **34 把枪械**：涵盖手枪、冲锋枪、霰弹枪、步枪与机枪，另有刀、Zeus x27、C4 与六种手雷。
- **弹道模型**：逐武器的散布、后坐力恢复、护甲穿透、命中部位倍率、距离衰减与穿墙。
- **压枪弹道**：手工调校的 AK-47 与 M4A4 弹道，其余武器使用确定性的程序化弹道。
- **倍镜、消音与点射**：AWP 与 SSG 08 光学瞄具、M4A1-S 与 USP-S 消音、Glock-18 与 FAMAS 点射模式。

### 投掷物与炸弹攻防

- **投掷物**：高爆手雷、闪光弹、烟雾弹、燃烧瓶、燃烧弹与诱饵弹，并按阵营区分可用性。
- **护甲与拆弹器**：护甲按命中部位吸收伤害，CT 拆弹器将拆包时间减半。
- **掉落武器**：阵亡玩家会掉落主武器与副武器，可供拾取。

### 战术机器人指挥 AI

- **四档难度**：简单、普通、困难与专家，分别调整反应时间、转身速度、瞄准误差、压枪控制、视野与听觉。
- **团队指挥**：双方各有一名执行指挥，负责分配角色、呼叫转点，并协调下包后的防守与回防。
- **感知模型**：视线检测、声音传播、闪光反应，以及随时间衰减的目标记忆。
- **38 名具名机器人**：稳定的角色名册让跨局记分板保持可读。

### Dust II 地图

- **完整报点**：T 出生点、外场、长门、坑位、A 点、CT 出生点、跳台、中路、Xbox、B 通道、B 点以及地图其余区域。
- **烘焙地图数据**：预烘焙的几何体、道具、斜坡与导航数据以紧凑的静态资源形式发布。
- **BVH 加速射线检测**：子弹、手雷、视线与移动均查询加速包围体层次结构。
- **碰撞斜坡**：不可见的移动专用斜坡让楼梯移动更顺滑，同时不会阻挡子弹或手雷轨迹。

### HUD 与视觉呈现

- **CS2 风格 HUD**：旋转雷达、购买菜单、记分板、击杀信息、回合计时、金钱、护甲与弹药。
- **程序化模型**：武器与角色在加载时由基础几何体组装，因此无需外部模型文件。
- **第一人称视图模型**：根据武器状态驱动拔出、待机、检视、换弹与开火动画。
- **合成音频**：定位枪声、脚步、换弹、无线电语音与炸弹提示音。
- **双语界面**：加载界面、购买菜单与提示均提供英文与简体中文标签。

## 🚀 快速开始 <a id="start"></a>

### 环境要求

- 支持 WebGL 2 与 ES 模块的现代桌面浏览器。
- 本地静态文件服务器。直接双击打开 `index.html` 无法运行，因为游戏使用 ES 模块与导入映射。
- 首次加载时需要访问固定版本的 jsDelivr CDN 模块。

### 本地运行游戏

```bash
git clone https://github.com/AMFI-Disable/DustIII.git
cd DustIII
python3 -m http.server 8000
```

在浏览器中打开 `http://localhost:8000`，点击画布以锁定鼠标。

### 静态部署

由于构建产物是纯静态包，任何静态托管服务都可以使用：GitHub Pages、Cloudflare Pages、Netlify 或 `nginx`。将托管目录指向仓库根目录，并以 `index.html` 作为入口文档即可。

> [!NOTE]
> 运行时通过 `index.html` 中的导入映射从 jsDelivr 加载 `three`、`three/addons/` 与 `three-mesh-bvh`。若需完全离线部署，请将这三个包放到 `js/vendor/` 下，并改写导入映射条目。

## 🧱 架构与设计 <a id="architecture"></a>

游戏是一个无需构建步骤的扁平 ES 模块应用。`index.html` 负责 DOM 外壳、HUD 样式与导入映射；`js/` 负责模拟与呈现。

```text
DustIII/
├── index.html                  # 外壳、HUD 样式、加载界面、导入映射
├── js/
│   ├── main.js                 # 启动、输入、相机、渲染循环、观战
│   ├── game.js                 # 回合、经济、购买、射击、伤害、炸弹
│   ├── player.js               # 玩家移动、碰撞、姿态
│   ├── bots.js                 # 机器人决策与团队指挥
│   ├── weapon_data.js          # 武器数值、槽位、规则、命中部位
│   ├── weapon_models.js        # 程序化武器网格与动画骨架
│   ├── characters.js           # 程序化角色网格与外观
│   ├── viewmodel.js            # 第一人称武器动画状态
│   ├── hud.js                  # 雷达、购买菜单、记分板、击杀信息
│   ├── audio.js                # 定位与合成音频引擎
│   ├── world.js                # 地图组装、材质、BVH、光照
│   ├── world_data.js           # 报点、出生点、点位、导航锚点
│   ├── world_nav.js            # 导航网格与寻路
│   ├── world_props.js          # 道具摆放与场景装饰
│   ├── world_materials.js      # PBR 表面混合
│   └── fx*.js                  # 粒子、烟雾、火焰、贴花、后处理
└── assets/
    ├── chars/                  # 角色贴图
    ├── fx/                     # 精灵、贴花、枪口火焰、烟雾序列帧
    ├── tex/                    # PBR 反照率、法线、ORM 贴图集
    ├── weapons/                # 武器美术参考
    ├── world/                  # 烘焙地图、道具、斜坡、导航数据
    └── ui/                     # 字体、图标、雷达图、UI 清单
```

### 设计说明

- **数据驱动地图**：静态地图载荷位于 `assets/world/`，加载时一次性获取，使模拟代码无需硬编码几何体。
- **规则单一来源**：`js/weapon_data.js` 中的 `RULES` 是回合计时、经济与比赛长度的唯一权威。
- **程序化美术**：武器与角色由代码生成，因此仓库无需携带大型二进制模型文件。
- **纯客户端权威**：机器人、伤害与经济均为确定性的本地模拟。没有需要信任的服务器，也没有网络同步。

## 🧪 诊断与验证 <a id="diagnostics"></a>

- **无渲染模式**：在 URL 后附加 `?norender` 可跳过开销较大的渲染循环，同时保持模拟运行，适合自动化冒烟加载与性能分析。
- **浏览器控制台**：所有系统都会向控制台输出日志，加载失败时会指明缺失的资源或模块。
- **手动冒烟测试**：打开页面，确认加载条达到 100%，点击锁定鼠标，购买一把手枪并完成一个回合。
- **资源完整性**：`js/` 引用的每张贴图、图标、字体与烘焙载荷都随 `assets/` 提供；加载器会立即报告任何缺失路径。

本仓库暂不包含自动化单元测试套件。欢迎贡献无头引擎探针。

## 🔒 隐私与安全第一 <a id="privacy"></a>

- **零遥测**：没有分析、没有追踪像素、没有崩溃上报、没有标识符。
- **零后端**：游戏完全静态，不存在账号、匹配或数据库服务。
- **仅本地状态**：设置、比赛状态与偏好仅保留在浏览器标签页或本地存储中。
- **可审计依赖**：唯一的运行时依赖是 `index.html` 导入映射中固定版本的 jsDelivr 包。在敏感环境部署前请审查或本地化它们。
- **无二进制下载**：仅通过源码检出与静态托管分发，本仓库不发布安装程序或可执行文件。
