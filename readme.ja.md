## ⚡ 概要とコアバリュー <a id="overview"></a>

DustIII は、名作 de_dust2 の 5v5 ボムディフューザルをブラウザ上で忠実に再現したプロジェクトです。あなたはライフルを手に 4 人のボット仲間とともにポジションを固め、5 人の敵ボットは連携したチームのように購入・ローテーション・実行・リテイクを行います。すべてのラウンドは単一ページ内でローカルにシミュレーションされます——アカウントもマッチメイキングもダウンロードもテレメトリもありません。

デスクトップ版 Chrome、Firefox、Safari の WebGL 2 を対象としています。コールドロード時は同一オリジンから静的マップとアートアセットを読み込み、その後は最新の GPU で 60 FPS 以上で試合全体を実行します。

## 🎮 主な特徴 <a id="features"></a>

### 競技ルールとエコノミー <a id="rules"></a>

- **MR12 形式**：先に 13 ラウンドを取った側の勝利。12 ラウンド終了時に陣営を交代し、最大 24 ラウンドで試合終了。
- **本格エコノミー**：開始資金 $800、上限 $16,000、$1,400 から $3,400 までの連敗ボーナス段階、キル報酬、プラント／ディフューズ報酬。
- **フリーズタイムと購入時間**：各ラウンド 15 秒のフリーズタイムと 20 秒の購入ウィンドウ。
- **完全なボムフロー**：3.2 秒のプラント、40 秒の C4 カウントダウン、10 秒のディフューズ、キット所持時は 5 秒。

### 武器サンドボックス

- **34 丁の銃器**：ピストル、SMG、ショットガン、ライフル、マシンガンに加え、ナイフ、Zeus x27、C4、6 種類のグレネード。
- **弾道モデル**：武器ごとの拡散、リコイル回復、アーマー貫通、ヒットグループ倍率、距離減衰、壁抜き。
- **リコイルパターン**：手調整された AK-47 と M4A4 のパターン、その他の武器には決定的な手続き生成パターン。
- **スコープ、サプレッサー、バースト**：AWP と SSG 08 の光学サイト、M4A1-S と USP-S の消音、Glock-18 と FAMAS のバーストモード。

### ユーティリティとボム処理

- **投擲物**：HE グレネード、フラッシュバン、スモーク、モロトフ、焼夷弾、デコイ。陣営ごとに入手可否が異なります。
- **アーマーとディフューズキット**：アーマーはヒットグループごとにダメージを吸収し、CT のディフューズキットは解除時間を半減します。
- **ドロップ武器**：死亡したプレイヤーはプライマリとセカンダリを落とし、拾得できます。

### 戦術ボットディレクター AI

- **4 段階の難易度**：Easy、Normal、Hard、Expert が反応時間、旋回速度、エイム誤差、リコイル制御、視野、聴覚を調整します。
- **チームディレクター**：各陣営の実行ディレクターがロール割り当て、ローテーションの指示、プラント後の防衛とリテイクを調整します。
- **知覚モデル**：視線判定、音の伝播、フラッシュ反応、時間とともに減衰するターゲット記憶。
- **38 名のネームドボット**：安定した名簿により、試合をまたいでもスコアボードが読みやすく保たれます。

### Dust II ワールド

- **完全なコールアウト**：T スポーン、アウトサイドロング、ロングドア、ピット、A サイト、CT スポーン、キャットウォーク、ミッド、Xbox、B トンネル、B サイトなどマップ全域を網羅。
- **ベイク済みマップデータ**：幾何形状、プロップ、ランプ、ナビゲーションデータを事前ベイクし、コンパクトな静的アセットとして配布。
- **BVH 高速レイキャスト**：弾丸、グレネード、視線、移動のすべてが加速 BVH を照会します。
- **クリップランプ**：移動専用の不可視ランプが階段移動を滑らかにし、弾丸やグレネードの軌道は遮りません。

### HUD と演出

- **CS2 風 HUD**：回転レーダー、購入メニュー、スコアボード、キルフィード、ラウンドタイマー、所持金、アーマー、弾薬。
- **手続き生成モデル**：武器とキャラクターはロード時にプリミティブから組み立てられるため、外部モデルファイルは不要です。
- **一人称ビューモデル**：武器状態に応じた抜刀、待機、検分、リロード、発砲アニメーション。
- **合成オーディオ**：定位のある銃声、足音、リロード、無線音声、ボムのビープ音。
- **バイリンガル UI**：ローディング画面、購入メニュー、プロンプトに英語と簡体字中国語のラベルを表示。

## 🚀 はじめかた <a id="start"></a>

### 動作環境

- WebGL 2 と ES モジュールに対応した最新のデスクトップブラウザ。
- ローカルの静的ファイルサーバー。ゲームは ES モジュールとインポートマップを使うため、`index.html` を直接開いても動作しません。
- 初回ロード時に固定バージョンの jsDelivr CDN モジュールへアクセスできること。

### ローカルで起動

```bash
git clone https://github.com/AMFI-Disable/DustIII.git
cd DustIII
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開き、キャンバスをクリックしてマウスをロックします。

### 静的ホスティング

ビルド成果物は純粋な静的バンドルなので、GitHub Pages、Cloudflare Pages、Netlify、`nginx` など任意の静的ホストで動作します。ホストの公開ディレクトリをリポジトリのルートに向け、`index.html` をエントリドキュメントとして設定してください。

> [!NOTE]
> 実行時は `index.html` のインポートマップを通じて `three`、`three/addons/`、`three-mesh-bvh` を jsDelivr から読み込みます。完全オフラインで運用する場合は、これら 3 パッケージを `js/vendor/` に配置し、インポートマップの項目を書き換えてください。

## 🧱 アーキテクチャと設計 <a id="architecture"></a>

本ゲームはビルド手順を必要としないフラットな ES モジュールアプリケーションです。`index.html` が DOM シェル、HUD スタイル、インポートマップを担当し、`js/` がシミュレーションと描画を担当します。

```text
DustIII/
├── index.html                  # シェル、HUD スタイル、ローディング画面、インポートマップ
├── js/
│   ├── main.js                 # 起動、入力、カメラ、レンダーループ、観戦
│   ├── game.js                 # ラウンド、エコノミー、購入、射撃、ダメージ、ボム
│   ├── player.js               # プレイヤー移動、衝突、姿勢
│   ├── bots.js                 # ボットの思考とチームディレクター
│   ├── weapon_data.js          # 武器数値、スロット、ルール、ヒットグループ
│   ├── weapon_models.js        # 手続き生成の武器メッシュとアニメーションリグ
│   ├── characters.js           # 手続き生成のキャラクターメッシュとスキン
│   ├── viewmodel.js            # 一人称武器アニメーション状態
│   ├── hud.js                  # レーダー、購入メニュー、スコアボード、キルフィード
│   ├── audio.js                # 定位・合成オーディオエンジン
│   ├── world.js                # マップ組み立て、マテリアル、BVH、ライティング
│   ├── world_data.js           # コールアウト、スポーン、サイト、ナビゲーションアンカー
│   ├── world_nav.js            # ナビゲーショングリッドと経路探索
│   ├── world_props.js          # プロップ配置と装飾
│   ├── world_materials.js      # PBR サーフェスブレンド
│   └── fx*.js                  # パーティクル、スモーク、炎、デカール、ポストエフェクト
└── assets/
    ├── chars/                  # キャラクターテクスチャ
    ├── fx/                     # スプライト、デカール、マズルフラッシュ、スモークシート
    ├── tex/                    # PBR アルベド、ノーマル、ORM テクスチャセット
    ├── weapons/                # 武器アートのリファレンス
    ├── world/                  # ベイク済みマップ、プロップ、ランプ、ナビゲーションデータ
    └── ui/                     # フォント、アイコン、レーダー画像、UI マニフェスト
```

### 設計ノート

- **データ駆動ワールド**：静的なマップデータは `assets/world/` にあり、ロード時に一度だけ取得されるため、シミュレーションコードに幾何形状をハードコードする必要がありません。
- **ルールの単一情報源**：`js/weapon_data.js` の `RULES` がラウンド時間、エコノミー、試合長の唯一の権威です。
- **手続き生成アート**：武器とキャラクターはコードから生成されるため、リポジトリに大きなバイナリのモデルファイルを含める必要がありません。
- **クライアント権威**：ボット、ダメージ、エコノミーはすべて決定的なローカルシミュレーションです。信頼すべきサーバーもネットワーク同期も存在しません。

## 🧪 診断と検証 <a id="diagnostics"></a>

- **レンダリングスキップ**：URL に `?norender` を付けると、負荷の高いレンダーループを省略しつつシミュレーションを継続できます。自動スモークロードやプロファイリングに便利です。
- **ブラウザコンソール**：すべてのシステムがコンソールへログを出力し、読み込み失敗時は欠落したアセットやモジュールを明示します。
- **手動スモークテスト**：ページを開き、ローディングバーが 100% に達することを確認し、クリックしてポインタをロックし、ピストルを購入して 1 ラウンドを完了します。
- **アセット整合性**：`js/` が参照するテクスチャ、アイコン、フォント、ベイク済みデータはすべて `assets/` に含まれ、ローダーが欠落パスを即座に報告します。

本リポジトリには自動ユニットテストスイートは含まれていません。ヘッドレスなエンジンプローブの貢献を歓迎します。

## 🔒 プライバシーとセキュリティ <a id="privacy"></a>

- **テレメトリゼロ**：分析、トラッキングピクセル、クラッシュレポート、識別子は一切ありません。
- **バックエンドゼロ**：ゲームは完全に静的で、アカウント、マッチメイキング、データベースサービスは存在しません。
- **ローカルのみの状態**：設定、試合状態、環境設定はブラウザタブまたはローカルストレージに留まります。
- **監査可能な依存関係**：実行時の依存は `index.html` のインポートマップで固定された jsDelivr パッケージのみです。機密環境へ配備する前にレビューするか、ローカルにベンダー化してください。
- **バイナリダウンロードなし**：配布はソースのチェックアウトと静的ホスティングのみで、本リポジトリからインストーラーや実行ファイルは公開しません。
