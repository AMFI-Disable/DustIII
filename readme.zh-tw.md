## ⚡ 概述與核心價值 <a id="overview"></a>

DustIII 是在瀏覽器中原生重現經典 de_dust2 5v5 拆彈循環的專案。你手持步槍，四名機器人隊友與你一同架點，五名敵方機器人會像一支協同作戰的隊伍那樣購買、轉點、執行戰術與回防。每一回合都在單一頁面中本地模擬——沒有帳號、沒有配對服務、無需下載、沒有遙測。

專案面向桌面版 Chrome、Firefox 與 Safari，需要 WebGL 2。冷啟動會從同源載入靜態地圖與美術資源包，隨後在現代 GPU 上以 60+ FPS 執行整場比賽。

## 🎮 主要特性 <a id="features"></a>

### 競技規則與經濟 <a id="rules"></a>

- **MR12 賽制**：先贏 13 回合者獲勝，第 12 回合後交換陣營，最多 24 回合結束比賽。
- **真實經濟**：初始 $800，上限 $16,000，$1,400 至 $3,400 的連敗補償階梯，擊殺獎勵，以及下包或拆包獎勵。
- **凍結與購買時間**：每回合 15 秒凍結時間與 20 秒購買視窗。
- **完整炸彈流程**：3.2 秒下包、40 秒 C4 倒數、10 秒拆包，攜帶拆彈器時為 5 秒。

### 武器沙盒

- **34 把槍械**：涵蓋手槍、衝鋒槍、霰彈槍、步槍與機槍，另有刀、Zeus x27、C4 與六種手榴彈。
- **彈道模型**：逐武器的散佈、後座力恢復、護甲穿透、命中部位倍率、距離衰減與穿牆。
- **壓槍彈道**：手工調校的 AK-47 與 M4A4 彈道，其餘武器使用確定性的程序化彈道。
- **倍鏡、消音與點放**：AWP 與 SSG 08 光學瞄具、M4A1-S 與 USP-S 消音、Glock-18 與 FAMAS 點放模式。

### 投擲物與炸彈攻防

- **投擲物**：高爆手榴彈、閃光彈、煙霧彈、汽油彈、燃燒彈與誘餌彈，並依陣營區分可用性。
- **護甲與拆彈器**：護甲依命中部位吸收傷害，CT 拆彈器將拆包時間減半。
- **掉落武器**：陣亡玩家會掉落主武器與副武器，可供拾取。

### 戰術機器人指揮 AI

- **四種難度**：簡單、普通、困難與專家，分別調整反應時間、轉身速度、瞄準誤差、壓槍控制、視野與聽覺。
- **團隊指揮**：雙方各有一名執行指揮，負責分配角色、呼叫轉點，並協調下包後的防守與回防。
- **感知模型**：視線偵測、聲音傳播、閃光反應，以及隨時間衰減的目標記憶。
- **38 名具名機器人**：穩定的角色名冊讓跨局計分板保持可讀。

### Dust II 地圖

- **完整報點**：T 出生點、外場、長門、坑位、A 點、CT 出生點、跳台、中路、Xbox、B 通道、B 點以及地圖其餘區域。
- **烘焙地圖資料**：預先烘焙的幾何體、道具、斜坡與導航資料以緊湊的靜態資源形式發佈。
- **BVH 加速射線偵測**：子彈、手榴彈、視線與移動均查詢加速包圍體階層結構。
- **碰撞斜坡**：不可見的移動專用斜坡讓樓梯移動更順暢，同時不會阻擋子彈或手榴彈軌跡。

### HUD 與視覺呈現

- **CS2 風格 HUD**：旋轉雷達、購買選單、計分板、擊殺訊息、回合計時、金錢、護甲與彈藥。
- **程序化模型**：武器與角色在載入時由基礎幾何體組裝，因此無需外部模型檔案。
- **第一人稱視圖模型**：依武器狀態驅動拔出、待機、檢視、換彈與開火動畫。
- **合成音訊**：定位槍聲、腳步、換彈、無線電語音與炸彈提示音。
- **雙語介面**：載入介面、購買選單與提示均提供英文與簡體中文標籤。

## 🚀 快速開始 <a id="start"></a>

### 環境需求

- 支援 WebGL 2 與 ES 模組的現代桌面瀏覽器。
- 本地靜態檔案伺服器。直接雙擊開啟 `index.html` 無法執行，因為遊戲使用 ES 模組與匯入對應。
- 首次載入時需要存取固定版本的 jsDelivr CDN 模組。

### 本地執行遊戲

```bash
git clone https://github.com/AMFI-Disable/DustIII.git
cd DustIII
python3 -m http.server 8000
```

在瀏覽器中開啟 `http://localhost:8000`，點擊畫布以鎖定滑鼠。

### 靜態部署

由於建置產物是純靜態包，任何靜態託管服務都可以使用：GitHub Pages、Cloudflare Pages、Netlify 或 `nginx`。將託管目錄指向倉庫根目錄，並以 `index.html` 作為入口文件即可。

> [!NOTE]
> 執行時透過 `index.html` 中的匯入對應從 jsDelivr 載入 `three`、`three/addons/` 與 `three-mesh-bvh`。若需完全離線部署，請將這三個套件放到 `js/vendor/` 下，並改寫匯入對應項目。

## 🧱 架構與設計 <a id="architecture"></a>

遊戲是一個無需建置步驟的扁平 ES 模組應用程式。`index.html` 負責 DOM 外殼、HUD 樣式與匯入對應；`js/` 負責模擬與呈現。

```text
DustIII/
├── index.html                  # 外殼、HUD 樣式、載入介面、匯入對應
├── js/
│   ├── main.js                 # 啟動、輸入、相機、渲染迴圈、觀戰
│   ├── game.js                 # 回合、經濟、購買、射擊、傷害、炸彈
│   ├── player.js               # 玩家移動、碰撞、姿態
│   ├── bots.js                 # 機器人決策與團隊指揮
│   ├── weapon_data.js          # 武器數值、槽位、規則、命中部位
│   ├── weapon_models.js        # 程序化武器網格與動畫骨架
│   ├── characters.js           # 程序化角色網格與外觀
│   ├── viewmodel.js            # 第一人稱武器動畫狀態
│   ├── hud.js                  # 雷達、購買選單、計分板、擊殺訊息
│   ├── audio.js                # 定位與合成音訊引擎
│   ├── world.js                # 地圖組裝、材質、BVH、光照
│   ├── world_data.js           # 報點、出生點、點位、導航錨點
│   ├── world_nav.js            # 導航網格與尋路
│   ├── world_props.js          # 道具擺放與場景裝飾
│   ├── world_materials.js      # PBR 表面混合
│   └── fx*.js                  # 粒子、煙霧、火焰、貼花、後處理
└── assets/
    ├── chars/                  # 角色貼圖
    ├── fx/                     # 精靈、貼花、槍口火焰、煙霧序列圖
    ├── tex/                    # PBR 反照率、法線、ORM 貼圖集
    ├── weapons/                # 武器美術參考
    ├── world/                  # 烘焙地圖、道具、斜坡、導航資料
    └── ui/                     # 字型、圖示、雷達圖、UI 清單
```

### 設計說明

- **資料驅動地圖**：靜態地圖載荷位於 `assets/world/`，載入時一次性取得，使模擬程式碼無需硬編碼幾何體。
- **規則單一來源**：`js/weapon_data.js` 中的 `RULES` 是回合計時、經濟與比賽長度的唯一權威。
- **程序化美術**：武器與角色由程式碼生成，因此倉庫無需攜帶大型二進位模型檔案。
- **純客戶端權威**：機器人、傷害與經濟均為確定性的本地模擬。沒有需要信任的伺服器，也沒有網路同步。

## 🧪 診斷與驗證 <a id="diagnostics"></a>

- **無渲染模式**：在 URL 後附加 `?norender` 可跳過開銷較大的渲染迴圈，同時保持模擬運行，適合自動化冒煙載入與效能分析。
- **瀏覽器主控台**：所有系統都會向主控台輸出日誌，載入失敗時會指明缺失的資源或模組。
- **手動冒煙測試**：開啟頁面，確認載入條達到 100%，點擊鎖定滑鼠，購買一把手槍並完成一個回合。
- **資源完整性**：`js/` 引用的每張貼圖、圖示、字型與烘焙載荷都隨 `assets/` 提供；載入器會立即回報任何缺失路徑。

本倉庫暫不包含自動化單元測試套件。歡迎貢獻無頭引擎探針。

## 🔒 隱私與安全第一 <a id="privacy"></a>

- **零遙測**：沒有分析、沒有追蹤像素、沒有崩潰回報、沒有識別碼。
- **零後端**：遊戲完全靜態，不存在帳號、配對或資料庫服務。
- **僅本地狀態**：設定、比賽狀態與偏好僅保留在瀏覽器分頁或本地儲存中。
- **可稽核依賴**：唯一的執行時依賴是 `index.html` 匯入對應中固定版本的 jsDelivr 套件。在敏感環境部署前請審查或本地化它們。
- **無二進位下載**：僅透過原始碼檢出與靜態託管分發，本倉庫不發佈安裝程式或可執行檔案。
